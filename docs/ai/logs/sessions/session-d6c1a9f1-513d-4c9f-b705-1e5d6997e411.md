## Scope (7 files, +1373/−111)
- **`packages/chrome-extension/src/content/tokens/page-harvester.ts` (NEW, 691 lines):** three-pass harvest — (1) `:root` custom-property pre-pass (origin `custom-property`, floor-exempt, categorized by value-shape + name hint); (2) bounded chunked `getComputedStyle` over visible elements (~500 cap, `requestIdleCallback` chunks of 50, single walk that tests visibility + samples + counts dropped in one pass); (3) CSSOM declared-value pass (per-sheet cross-origin `SecurityError` caught per `inspection/css-rules.ts`; recurses @media/@supports/@layer; 8000-rule ceiling; shorthand expansion for margin/padding/gap/border-radius/border-color). Union → normalize (rgb/rgba/hsl/hex→lowercase hex; unit-normalized lengths; font-family/weight/line-height/shadow) → dedup (highest-confidence origin wins) → frequency floor (≥2, custom-property exempt) → per-category top-N caps (deterministic tiebreak). - **`page-value-store.ts` (NEW, 129 lines):** `InferredOption` (extension-local, never `DesignToken`) + `PageValueStore` (`load`/`getForProperty`/`getForCategory`/`clear`/`onUpdate`/`loaded`), indexed by property + category, ranked by frequency. `clear()` idempotent (no-op notify when empty).
- **`content/index.ts`:** instantiate `PageValueStore`; pass to Color/Typography/Layout editors; `scheduleHarvest`/`runHarvest` (generation-based abort, gated on empty TokenStore, idle-scheduled); `supersedePageValues`/`reconcilePageInference` wired into `onTokenData`/`onTokenUpdate` (non-empty tokens clear + abort; empty set re-arms); debounced `MutationObserver` (750ms, ≥25 net element mutations) for SPA re-harvest; `refreshActiveValueEditor` on store/token updates; `teardownHarvest` in deactivate.
- **`editing/colors.ts`:** exported `buildPageValueColorGroup` (dashed "observed" swatch group, distinct from token 2px-solid) + `pageValueHeading`; no-token branch renders page swatches above the freeform `buildColorInput` floor.
- **`editing/typography.ts`:** `buildTypographyValueControl` + `buildFallbackSelect` ("On this page" optgroup above "Common"/"Values" freeform defaults for font-size/family/weight); color control reuses `buildPageValueColorGroup`.
- **`editing/layout-editor.ts`:** `buildPageGutterSelect` ("On this page" optgroup for gap/row-gap/column-gap; `auto` + freeform escape retained).
- **`packages/shared/src/diff.ts`:** additive-optional `PropertyChange.fromPageInference?: true` (spec Internal Design § Components assigns it to Brief 2; no `WS_PROTOCOL_VERSION` bump). Page-inferred selections emit `fromPageInference: true` with **no `toToken`/`fromToken`**.

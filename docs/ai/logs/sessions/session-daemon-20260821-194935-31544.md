## Brief

Inline Text Styling — Build (Brief 2 of 2)

mini-toolbar and keyboard shortcuts. Flow markup through the full pipeline: `TextChange` contract
(`fromHtml`/`toHtml`), prompt serializer fenced block, markup-safe undo/redo, and exact-restore
cancel via `innerHTML`.

## Decisions Made

- `inline-format.ts` (pure formatting module) created instead of `inline-toolbar.ts` — toolbar
  lifecycle lives in `text.ts`; separates pure DOM logic (testable without shadow DOM) from
  session lifecycle
- `fromHtml` condition: present when `sanitizedOriginalHtml !== originalText` (original had
  markup); `toHtml`: present when `newHtml !== newText` (result has markup) — matches spec
  precisely, avoids over-inclusion
- `ShadowRoot.querySelector('#id')` used for style deduplication instead of non-standard
  `getElementById` (ShadowRoot.getElementById does not exist in W3C DOM spec)

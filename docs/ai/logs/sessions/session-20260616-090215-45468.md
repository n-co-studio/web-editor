# Session 20260616-090215-45468 — Queue side panel (right dock) + toolbar-icon popup

## Brief
Operator request (Prompt B): convert the Change Request Queue (ReviewPanel) from a
floating, toolbar-anchored panel into a full-height panel docked to the RIGHT edge of
the viewport, mirroring the bottom-docked DevTools panel. Also make the Chrome toolbar
icon open/close the queue while retaining the extension on/off toggle. Operator was
open to UX alternatives and asked for UX agents to weigh in.

## Session Type
- `standard`, solo. Mode: `auto`.
- Branch: `feature/queue-side-panel` (from main).

## Phase Trace
`init → drift-check (no bundle, RC=1 → legacy plan path) → plan → approval → build → review → verify → commit → close`.

## Key Decision — icon UX
Both ux-designer and ux-strategist independently recommended a right-click context
menu (preserves the one-click toggle; MV3 default_popup suppresses onClicked). Operator
was presented the tradeoff via AskUserQuestion and chose the **popup dropdown** anyway.
Implemented per operator choice: `default_popup` with two actions (toggle extension,
open/close queue); `chrome.action.onClicked` removed.

## What Shipped
- `review-panel.ts` — float → right-edge full-height dock. Flex column: pinned header,
  scrollable body (`flex:1 1 auto; minHeight:0; overflowY:auto`), pinned action bar.
  Left-edge resize handle (`ew-resize`) with pointer drag, hover affordance, dblclick
  reset; width persisted to `chrome.storage.session` (try/catch, mirrors DevTools
  saveHeight). Removed makeDraggable/anchorPos/userDragged/reposition.
- `popup/popup.html` + `popup/popup.ts` — new toolbar popup. GET_STATE drives live
  labels; TOGGLE_EXTENSION / TOGGLE_QUEUE_PANEL dispatched to the tab; executeScript
  fallback when content script not injected; aria-pressed on both buttons; disabled
  "unavailable on this page" state.
- `index.ts` — show() de-anchored; reposition('review') removed; added GET_STATE +
  TOGGLE_QUEUE_PANEL handlers and toggleQueuePanel() (activates editor if off).
- `service-worker/index.ts` — removed onClicked (popup supersedes); badge/icon handlers kept.
- `manifest.json` — action.default_popup = popup.html.
- `esbuild.config.js` — popup.ts entry (dist/popup.js) + copy popup.html.
- `constants.ts` — QUEUE_PANEL_DEFAULT_WIDTH 340 / MIN 260 / MAX_WIDTH_RATIO 0.5.
- `types.ts` — TOGGLE_QUEUE_PANEL added to ChromeMessageType.

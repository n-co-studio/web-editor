## Summary
Eliminated base64 from visual diffs and made every emitted image reference an
apply-correct served path (`/images/<name>`, leading `/public` stripped). The
media file picker no longer reads picked files into `data:` URIs — it emits a
blob URL for live preview plus a `pendingUpload` side-channel and a provisional
`/images/<name>` path. The MCP-server bridge is now the resolution point: it
scans **every** data-URL carrier (attribute changes, `InsertChange.outerHTML`,
and `background-image` property changes), persists/dedups assets to
`public/images` returning `/images/<name>`, and truncates oversized/unresolvable
assets instead of inlining multi-MB blobs. Foundation for Brief 2 (#29).

## Summary

Round one of an operator-requested "design-practice texture" pass on the classic page (`/`): take the dot grid
that lived on the hero placeholder and lift it onto the whole page background, subtly. The operator framed it as
the first of several rounds (lines and other nods to follow).

## Changes (12 lines)

- `src/tokens.css` — new `.nco-paper` class: `background-color: var(--color-bg)` + an inline SVG data-URI
  dot-grid `background-image` (24px tile, faint `#0f0f0f` at 6% opacity — an SVG pattern, not a CSS color
  gradient, to stay crisp and match the line-art idiom).
- `src/App.tsx` — classic root `<div>` now uses `className="nco-paper"`; its inline `background` shorthand was
  removed (a shorthand would have reset `background-image` to none and wiped the texture).
- `src/components/Hero.tsx` — removed the duplicate dot `<pattern>` from `HeroPlaceholder` (dots now live on the
  page) and set the hero panel background to `var(--color-bg)` (solid white) so it reads as a clean plane over
  the dotted page. The line-art selection motif stays.

The `/motion` page is unaffected — it paints its own dark `--m-bg` on `.nco-motion`, which covers any page
texture.

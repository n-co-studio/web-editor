## What changed

- `packages/mcp-server/package.json`: `"zod": "^4.6.6"`. A `^3.25 || ^4`
  range was rejected because every zod 3 is inside the advisory range. The
  test script adds `--test-timeout=30000` and `src/tool-schemas.test.ts`.
- `packages/mcp-server/src/server.ts`: all 11 tool inputs are built with
  `inputObject(shape) = z.object(shape).meta({ additionalProperties: false })`.
  Under zod 4 the SDK's `toJsonSchemaCompat` dropped `additionalProperties:
  false`, and `.meta` restores it. `strictObject` was not used because it
  would reject unknown keys that are stripped today. `registerTools` and
  `SERVER_INSTRUCTIONS` are exported for the test.
- `src/tool-schemas.test.ts` + `src/__fixtures__/tools-list.json`: a
  `tools/list` snapshot against a zod 3.25.76 baseline (11 tools), plus
  validation pins.
- `package-lock.json`: a single `zod@4.6.7`.
- `CHANGELOG.md`: `### Security` under `[Unreleased]`.
- `docs/ai/logs/known-issues.md`: a KL-3 RESOLVED bullet, and the KL-3
  heading no longer says "unfixable".

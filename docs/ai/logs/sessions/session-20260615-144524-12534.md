# Session 20260615-144524-12534 — Status toolbar icon + image parallax + flex/grid spacing panel

## Brief
Three operator requests on one branch: (1) wire the operator-provided Chrome toolbar
icons (icon/*.png: disabled, active, red, orange, green) to reflect extension status;
(2) add an image "parallax" feature — convert an image to a full-width fixed-background
block whose height is set with the existing dimensions tool; (3) add a panel to edit
gaps/gutters/spacing of a flex or grid container ("auto-layout group").

## Confirmed decisions (operator)

## What Shipped

### Feature A — Status-driven toolbar icon
- `icon/*.png` (+ .svg) committed as operator assets; `esbuild.config.js` copies the
  repo-root `icon/` to `dist/icons/status/`. `manifest.json` `default_icon` →
  disabled PNG (keyed-object form, store-validator conformant).
- `shared/types.ts`: `UPDATE_ICON` message + `IconStatus` type.
- `service-worker/index.ts`: `UPDATE_ICON` handler → `chrome.action.setIcon`/`setTitle`
  (both `.catch`-guarded) keyed by status.
- `content/index.ts`: `computeIconStatus()` + `refreshExtensionIcon()` from
  {mode, lastConnectionStatus, queue.pendingCount, lastDiffApplied, lastErrorActive},
  called from activate/deactivate, `handleStatusChange`, `queue.onChange`, and the
  WS `onDiffApplied`/`onDiffAck`/`onError` callbacks.

### Feature B — Image parallax (img ⇄ fixed-background div)
- New pure module `editing/parallax.ts` (`getParallaxBlockReason`, `wouldEnableParallax`,
  `toParallaxBlock`, `fromParallaxBlock`) with `data-parallax*` markers for exact revert.
- `editing/media.ts`: a "Parallax" toggle (Convert / Revert) for images and parallax
  blocks; tooltip directs to the dimensions tool for height.
- `content/index.ts` `makeParallaxCommit`: builds the diff before the swap, replaces the
  node, records a single `'replace'` history entry, selects the new element.
- `batching/diff-builder.ts` `buildReplace`: one VisualDiff carrying both `removeChanges`
  and `insertChanges` (insert with full `outerHTML`) — no new shared diff types.
- `history.ts`: new `'replace'` entry (undo/redo/resetAll via `replaceChild`).

### Feature C — Flex/grid spacing panel
- `selection/panes/layout-section.ts`: a "Spacing" subgroup (gap, row-gap, column-gap,
  padding) for flex/grid containers, reusing `buildSubGroup` + `InlineEditor` +
  `onPropertyChange` + `commitEdit`; `gap` moved out of the container prop lists.
- `shared/dom-utils.ts`: added `rowGap`, `columnGap`, `padding` to `ComputedStyleSnapshot`
  and populated them in `createStyleSnapshot` (without these the new rows rendered blank).

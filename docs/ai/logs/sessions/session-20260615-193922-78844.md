# Session 20260615-193922-78844 — New "Layout" toolbar tool: gutters + proportion toggle

## Brief
Operator: the devtools properties pane is not editable / not picked up by the change
queue (a known issue, NOT being fixed now). Wanted, **from the toolbar** and through the
working commit pipeline: (1) adjust gutters (gap/row-gap/column-gap) on flex/grid
containers using spacing tokens; (2) toggle a container between layout ratio presets
(50/50, 2/3+1/3, thirds, fourths) **preserving the content** in each child block, for
both flex and CSS grid.

## Session Type
- `standard` (Prompt B). Mode: `review`. Branch: `feature/layout-tool` (from main).

## Decisions (operator-confirmed)
- One **new "Layout" toolbar tool** housing both Gutters and Proportions (not extending
  the Spacing tool; the new tool is the working replacement for the broken devtools pane).
- Proportions support **flex + CSS grid**.

## What Shipped
- `shared/types.ts`: `EditMode` += `'layout'`.
- `toolbar.ts`: `'layout'` in `TOOL_ORDER` (after spacing), `TOOL_LABELS` ('Layout'),
  and a 2-column blocks `ICONS.layout` glyph (existing button loop wires it up).
- `editing/insert-catalog.ts`: `export` the existing `LAYOUT_RATIOS` (reused by the
  proportion toggle — same weights as the insert presets).
- **`editing/token-select.ts`** (new): shared `buildTokenSelect` + `extractUnit`,
  extracted from `SpacingEditor`'s private method (Pragmatist finding — one implementation).
- `editing/spacing.ts`: delegates to the shared helper; private copy + local `extractUnit`
  removed (behavior preserved: auto option, unmatched-current fallback, preview, toToken).
- **`editing/layout-editor.ts`** (new): floating panel for a flex/grid container.
  - Gutters: gap/row-gap/column-gap token dropdowns (tokens from `getForProperty(prop)`
    || `getForCategory('spacing')`); commit via `onCommit → commitEdit`.
  - Proportions: `LAYOUT_RATIOS` filtered to the container's direct-child count; active
    preset highlighted (flex via flex-grow; grid via inline grid-template `fr`). Non-
    containers show a hint.
- `index.ts`: instantiate/cleanup `layoutEditor` mirroring `spacingEditor`; `mode ===
  'layout'` branch; `makeProportionsCommit(container, weights)` — flex sets each child's
  `flex` weight (one queued change per changed child, skips already-correct children);
  grid sets `grid-template-columns/-rows` to `fr` weights (one queued change). Content
  preserved — sizing only, no DOM moves.

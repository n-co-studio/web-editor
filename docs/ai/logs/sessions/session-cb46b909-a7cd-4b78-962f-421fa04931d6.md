## Summary

Brief 2 of 2 of the `parallax-editor` task group. Brief 1 (commit `101651b`) authored feature-009 and the `StylesheetChange`/`ScriptBehaviorChange` data contracts. This brief implemented against them, evolving the existing `<img>` <-> fixed-background swap into a multi-mechanism, strength-tunable parallax editor.

Four mechanisms, all driven by one canonical `--parallax-strength` (0-1, default 0.3) via per-mode `calc()`:
- **fixed** - `background-attachment: fixed`; strength zooms `background-size` (iOS-unsupported warning surfaced).
- **transform-3d** (default) - perspective wrapper + `translateZ` inner with compensatory scale; `data-parallax` on the outermost element.
- **scroll-driven** - `@keyframes` + `@supports (animation-timeline: scroll())` wiring + `@supports not(...)` 3D fallback, carried as a `StylesheetChange`.
- **js-scroll** - declarative `ScriptBehaviorChange` (`parallax-scroll`, rAF, `respectsReducedMotion`).

Every CSS mechanism emits a `@media (prefers-reduced-motion: reduce)` zeroing `StylesheetChange`; js-scroll short-circuits via `matchMedia` (WCAG 2.3.3).

## Summary

Built a second, distinctly-styled page for the demo-app at **`/motion`** (coexists with the classic page at
`/`; headers cross-link). Operator brief: a completely different, "much more dynamic and engaging" design,
avoiding AI clichés (no purple, no color gradients), with animated SVG / scroll-triggered animation and
**generated graphics — no placeholders**.

## Design

Dark "kinetic blueprint": near-black `#0c0e0f` canvas, off-white ink, ONE flat coral accent `#ff5a36`, hairline
SVG grid. Fonts: minion-3-display (display) + hero-new (body) + JetBrains Mono (labels); NCO logo in off-white.
Scoped under `.nco-motion` so the classic page's tokens are untouched.

## Animation — CSS only (no JS runtime)

`motion/motion.css` utilities: `.m-reveal` (scroll-driven via `animation-timeline: view()`), `.m-draw`
(stroke-dashoffset + opacity, paths use `pathLength={1}`), `.m-pulse`, `.m-travel` (diff packet), `.m-float`.
All `@media (prefers-reduced-motion)` guarded; degrade to static where unsupported.

## Graphics — generated by sub-agents

Four animated SVG components in `src/motion/graphics/` were authored by parallel **builder sub-agents** and
integrated with corrections: `HeroSelection` (the selection scene), `McpFlow` (editor→MCP→agent with a
travelling packet), `TokenSnap` (value snapping to a token scale), `EditModes` (3×3 mode grid). Integration
fixes: removed local `<style>` blocks that would have clobbered the shared `.m-draw`/`.m-travel`; fixed a
malformed hero cursor; replaced a fragile `pathLength`-on-`<g>` draw in EditModes with static glyphs.

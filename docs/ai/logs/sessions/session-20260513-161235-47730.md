## Goal
Brief 2 of the `breakpoint-awareness` task group. Capture CSS rules defined at non-active viewport media-query breakpoints during element inspection and propagate this multi-breakpoint context end-to-end (diff → MCP → copy-prompt) as additive `allBreakpointSources` on `PropertyChange`, so the receiving AI can reason about responsive rules at other breakpoints without switching viewports. Active-viewport behaviour of the existing inspection path is unchanged — new context is additive and opt-in at the inspection-call layer.

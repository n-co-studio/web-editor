## Design Insight
The editor records DOM edits as diffs that the MCP server hands to Claude Code to
rewrite source. Investigation surfaced a pre-existing serialization gap: the
copy/paste flow cloned full `outerHTML` into the live DOM but called
`buildInsertChange` with an empty styles array and no children — so the diff that
reached the source rewrite was just an empty `<tag>`, dropping the entire subtree.
Duplication needs the same full-subtree fidelity, so the fix is shared and also
repairs paste.

  reordered to build before mutation, mirroring paste.
- Critic: Cmd+D suppressed the native bookmark even with no selection → gated
  preventDefault on a live selection (mirrors Cmd+C).
- UX CRITICAL: "Duplicate all" never disabled → disabled when all elements blocked.
- UX/Design-health: extracted the `16px`/`40px` magic values; relabelled the category
  "Layout Presets" to disambiguate from the existing "Layout" category.

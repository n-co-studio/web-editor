## Key fact — token discovery (no default set)

The MCP server (`packages/mcp-server/src/tokens.ts`) ships **no default token set**. It scans the target
project's `cwd` (tailwind config, `design-system.md`, `src/**/*.css` custom properties). So the demo-app's own
`src/tokens.css` IS the authoritative token set the tool snaps to — there is nothing to "override".

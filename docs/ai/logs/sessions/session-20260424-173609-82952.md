# Session 146 — 2026-04-25 — Delete Element via RemoveChange (not display:none)

**Status:** complete
**Decisions:** none
**Branch:** `fix/delete-element-removechange-v2`

## Goal
The toolbar delete button removed the element from the local DOM but emitted a fabricated `display: none` `PropertyChange` in the diff sent to Claude via MCP. Claude then edited the source to add `display: none` instead of physically removing the JSX node. Replace that with a real removal action in the diff payload.

## Root Cause
`deleteSelectedElement()` in `packages/chrome-extension/src/content/index.ts` built a `PropertyChange[]` with `{ property: 'display', fromValue, toValue: 'none' }` and called `diffBuilder.build(info, changes)`. The local DOM call was `el.remove()`, but the diff that flowed to MCP/Claude described a CSS edit, not a removal — so the source-code consumer matched the diff to a CSS modification.

There was no `RemoveChange` parallel-array type on `VisualDiff` (insert/reorder/group/reparent/attribute/text all existed; remove did not).

## Changes Made
- `packages/shared/src/diff.ts` — Added `RemoveChange { type, tagName, containerSelector, removedIndex }`. Added `removeChanges?: readonly RemoveChange[]` to `VisualDiff`.
- `packages/shared/src/index.ts` — Re-exported `RemoveChange`.
- `packages/chrome-extension/src/content/batching/diff-builder.ts` — Added `buildRemove(elementInfo, removeChange)` mirroring the existing `buildInsert`.
- `packages/chrome-extension/src/content/index.ts` — `deleteSelectedElement()` now constructs a `RemoveChange` and calls `diffBuilder.buildRemove(info, removeChange)`. The `display: none` `PropertyChange` is gone; `commitEdit` is called with `[]` for changes. Local `el.remove()` and the `'removal'` history entry are unchanged (already correct — undo/redo never used the discarded `changes` array).
- `packages/chrome-extension/src/content/batching/prompt-serializer.ts` — Added a "Remove Changes" markdown section, parallel to insert/reorder/group/text sections.
- `packages/chrome-extension/src/content/batching/review-panel.ts` — Added a remove row with a red `del` badge. Included `removeChanges?.length` in the changeCount tally for the "Removed" section.
- `packages/mcp-server/src/server.ts` — Extended the `get_pending_visual_changes` tool description to document `removeChanges` and explicitly tell Claude to physically delete the JSX node, not hide it via CSS.
